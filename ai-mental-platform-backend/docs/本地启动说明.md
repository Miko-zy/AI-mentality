## 二、启动顺序（Redis → 后端 → 前端）

Redis 必须最先启动：后端登录/注册/鉴权都会读写 Redis，Redis 不在会直接返回“系统内部错误”。

### 1. 启动 Redis

```powershell
cd D:\mysql
.\redis-server.exe redis.windows.conf
```

保持这个窗口不要关。另开一个 PowerShell 验证：

```powershell
D:\mysql\redis-cli.exe -h 127.0.0.1 -p 6379 ping
# 期望输出：PONG
```

### 2. 启动后端

方式 A（推荐，IDEA）：打开项目，运行 `com.aimental.AiMentalPlatformApplication`。

方式 B（命令行，IDEA 自带 Maven；首次会下载插件，较慢）：

```powershell
cd C:\Users\Administrator\Desktop\work\AI心理\ai-mental-platform-backend
& 'D:\IntelliJ IDEA 2026.2.4\plugins\maven-plugin\lib\maven3\bin\mvn.cmd' -DskipTests spring-boot:run
```

成功标志（日志里出现）：

```
Tomcat started on port(s): 8080 (http) with context path '/api'
Started AiMentalPlatformApplication in x.xxx seconds
```

存活检查（未登录访问受保护路径，应返回 401）：

```powershell
curl.exe --noproxy '*' -i http://localhost:8080/api/
```

### 3. 启动前端

```powershell
cd C:\Users\Administrator\Desktop\work\AI心理\ai-mental-platform-frontend
D:\npm.cmd run dev
```

也可以双击 `启动前端.bat`。看到 `VITE v4.5.14 ready` 后访问：

```
http://localhost:5173/login
```

> 注意：本机 Vite 只绑定了 IPv6 的 `::1`，请用 `localhost` 访问；用 `127.0.0.1:5173` 会连不上。
> 如需 IPv4 访问，改用：`D:\npm.cmd run dev -- --host 127.0.0.1`

## 三、停止服务

```powershell
# 停前端（占用 5173 的进程）
$p = (Get-NetTCPConnection -LocalPort 5173 -State Listen).OwningProcess; Stop-Process -Id $p -Force

# 停后端（占用 8080 的进程）
$p = (Get-NetTCPConnection -LocalPort 8080 -State Listen).OwningProcess; Stop-Process -Id $p -Force

# 停 Redis
Get-Process redis-server -ErrorAction SilentlyContinue | Stop-Process -Force
```

IDEA 里启动的后端，直接在 Run 面板点红色停止按钮即可。

## 四、数据库脚本与重装

- 完整初始化脚本：`ai-mental-platform-backend\docs\init_full.sql`
  - 建库（utf8mb4 / utf8mb4_unicode_ci）+ 20 张表 + 量表/题目/徽章/管理员/示例课程种子数据

因为项目路径含中文，`mysql.exe` 的 `source` 直接读中文路径会失败。推荐用 Navicat 运行 SQL 文件；命令行请先复制到英文路径：

```powershell

& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' -uroot -p123456 --default-character-set=utf8mb4 -e "source D:/temp/init_full.sql"
```

导入后核对：

```powershell
& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' -uroot -p123456 --batch -e "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='ai_mental_platform'; SELECT scale_id,scale_name,total_question_num,reliability FROM ai_mental_platform.mental_scale;"
```

## 五、已知不可用项

1. **管理端登录缺失**：后端只有 `/api/user/register`、`/api/user/login`、`/api/user/login/email`，没有管理员登录接口；普通用户 token 的角色固定为 `user`，访问 `/api/admin/**` 会返回 403。数据库里的 `admin` 账号目前只是数据，前端 `/admin` 页面进不去。
2. **邮件验证码是“假发送”**：未配置 SMTP，注册时后端跳过验证码校验，前端随便填 6 位数字即可；“发送验证码”按钮依赖 Redis，验证码只打印在后端日志里。
3. **徽章种子是占位数据**：原 `前文.txt` 的徽章 INSERT 未随迁移带来，`init_full.sql` 里放了一条可运行的“初次打卡”占位，拿到原文后可单行替换。

## 六、常见故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录/注册返回 `{"code":500,"message":"系统内部错误"}` | Redis 未启动 | `redis-cli ping` 应为 PONG；后端日志会看到 `RedisConnectionException ... 6379` |
| 启动报 `Port 8080 was already in use` | 旧后端进程未退 | 按第三节停 8080 端口占用进程 |
| 启动报 `Unknown column 'is_deleted'` 等 SQL 错误 | 库表不是最新脚本建的 | 重新执行 `init_full.sql`（会清空数据） |
| `/api/admin/**` 返回 403 | 没有管理员登录入口 | 属已知缺口，需补管理员登录接口后使用 |
| IDEA 里 Maven 报 “Maven home directory is invalid” | Maven Home 指向旧电脑的 `D:\jdk-21` | Settings → Build Tools → Maven → 选 **Bundled (Maven 3)** |
| 首次 `mvn spring-boot:run` 很慢 | 无阿里云镜像，走 Maven 中央仓库 | 在 `C:\Users\Administrator\.m2\settings.xml` 配阿里云 mirror（可选） |
| IDEA 编译报目标版本/语言级别错误 | 项目 SDK 是 JDK 27，pom 是 release 17 | 装 JDK 17，Project Structure 里 SDK/Language Level 都改为 17 |
| 浏览器打不开 `127.0.0.1:5173` | Vite 绑定在 IPv6 `::1` | 用 `localhost:5173`，或加 `--host 127.0.0.1` |
| 中文路径执行 `mysql -e "source ..."` 失败 | 客户端对中文路径编码处理有问题 | 复制 SQL 到英文路径（如 `D:\temp`）或改用 Navicat |
